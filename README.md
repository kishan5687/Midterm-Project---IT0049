## Project Overview
A web-based Point of Sale (POS) System developed as a midterm project for **IT0049**. The system helps organize product inventory, customer records, user accounts, and sales transactions in one place. This project was built using the CodeIgniter 4 PHP framework. It provides a simple interface for managing store information and recording sales. When a sale is processed, the system calculates the total price, saves the transaction, and updates the remaining product stock.

## Features

- **Login and logout** – access the system through a login page.
- **Dashboard** – access the main areas of the system.
- **Product management** – add, view, edit, and delete products, including product images, prices, and stock quantities.
- **Customer management** – maintain customer names, email addresses, and phone numbers.
- **User management** – manage system user records.
- **Sales recording** – select a product and optionally a customer, enter a quantity, and record the transaction.
- **Stock updates** – deduct the sold quantity from the product's available stock.
- **Sales history** – review previously recorded transactions.
- **Form validation** – validate important product and customer fields before saving.
